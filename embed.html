English: how to add it

    

  1. Copy the code above.
    2. 

  2. Paste it where you want the question to appear:

    • WordPress: edit the page, add a Custom HTML block, paste and update. In a sidebar, use a Custom HTML widget.
      • 

    • Wix: Add → Embed code → Embed HTML, paste, then set a height of about 520 px.
      • 

    • Squarespace: add a Code block and paste.
      • 

    • Any other site: paste it into the page HTML.
    3. 

  3. That's it. The question changes every day at midnight Cyprus time.
    4. 



The widget takes the full width of the box you put it in, so it works in a wide column or a narrow sidebar. Its styles sit in a shadow DOM, so they can't change your page's styles and your page's styles can't break it. It doesn't set cookies or use local storage. The only network request is one small file, qotd.json, from GitHub Pages. The footer link to our free practice test includes your name (?utm_source=embed&p=yourname), so we can see which sites send visitors. It's free and there's nothing to sign up for.

Who it's for


It suits relocation and immigration advisers, law firms, language schools, Greek teachers, community groups and expat news sites in Cyprus. In short, any site whose readers apply for naturalisation or long-term residence. The questions come from our public practice material: the free practice test, the topic pages and the Greek trap words. Each answer links to an official or reputable source.
